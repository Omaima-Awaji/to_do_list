# To-Do List 📝

A simple command-line to-do list app built with Python that saves your tasks to a file.

## Features
- Add new tasks
- View all current tasks
- Remove tasks by number
- Tasks are saved to tasks.txt so they persist between sessions

## How to Use
Run the script:

python to_do_list.py

Then choose from the menu:
1. Add task - enter a new task to your list
2. View tasks - display all current tasks
3. Remove task - pick a task by number to delete it
4. Exit - close the app

## Example

1. Add task
2. View tasks
3. Remove task
4. Exit
Enter number: 1
What is new on your schedule? Buy groceries
Task is added!!

## Files
- to_do_list.py - main script
- tasks.txt - auto-generated file where your tasks are saved

## Requirements
- Python 3.x
- No external libraries needed
